An end-to-end ML system for real-time stock price prediction: Kafka streaming ingests live data,
DistilBERT scores news sentiment, an XGBoost classifier produces the prediction, a FastAPI backend
serves it, and a React dashboard visualises it — built entirely on free-tier APIs (yfinance, etc.).
